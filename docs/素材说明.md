## 本次替换

新趴姿来自用户目录 `E:\TAPWORK\动画素材_01_趴姿晃头摆腿`。取根目录的 36 张 RGBA PNG，按文件名升序复制；`frame_000.png` 对应工程 `frame_01.png`，`frame_035.png` 对应 `frame_36.png`。仅调整文件名，图片字节保持一致。制作目录里的脚本、参考图、视频和预览没有作为运行素材打包。

播放速度采用素材 `animation_project/config.json` 的规定：每帧 125 毫秒，8 FPS，4.5 秒一圈，末帧直接回到首帧；不重复插入首帧，不补帧、不改变速度。其余五个动作保留原有素材，但全部默认停用。

共 76 张 PNG。`integrity.json` 保存源文件名、SHA-256、字节数与趴姿时间参数；`npm run check` 校验帧数、序号、哈希、RGBA 和同组尺寸。

## 播放与显示

`app/shared/actions.ts` 定义动作参数与默认停用列表；`app/renderer/usePetAnimation.ts` 先解码全部所需帧，再以 requestAnimationFrame 和时间轴绘制到 Canvas。避免播放中反复更换图片地址与首次解码造成闪烁。多个手动启用的动作只在完整循环结束后切换。

所有趴姿帧共用一个固定显示范围：覆盖 36 帧所有非透明像素的并集，位置为原画布 x=28、y=114，大小 395 × 229。仅略过外围完全透明留白，不修改原图、不裁掉角色像素、不逐帧改变边界。这样角色保持适当大小且不会因各帧外接框变化而抖动。透明区域穿透按当前帧 Alpha 判断。

打开菜单、输入框或切换默认动作下的在线／忙碌状态，循环时钟保持连续。动作偏好实际变化时重新选择动作；Windows 要求减少动态效果时显示静态首帧。

## 默认设置与升级

菜单复选框表示“停用这个动作”：默认第一项不勾选，另外五项勾选。取消勾选可重新开启其他动作。全部停用时显示新趴姿首帧，状态仍由文字与状态点表达。

0.1.0 的默认设置是全部开启。升级 0.1.1 时通过 `animationDefaultsVersion` 进行一次性迁移，设置为只开启趴姿；保留大小、位置、置顶、自启和中继地址。迁移完成后，用户后续选择正常保存，不会每次启动重新关闭。

## 验证

`npm run test:animation` 在真实 Electron 中检查旧设置迁移、36 帧出现、两次 35→0 衔接、菜单／输入框／状态不重置、透明区域穿透、全部停用、手动开启与减少动态效果。单元测试验证 125 毫秒帧时长和原 8 秒边界不截断动画。两台实际电脑及不同刷新率、高 DPI 下的主观流畅度仍需使用者体验确认。
