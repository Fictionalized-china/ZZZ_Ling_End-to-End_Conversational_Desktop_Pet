# 铃宝动画素材说明

六组素材已经从原始中文文件夹移动至 `assets/pet/`。保留全部原图、透明通道、帧文件名和像素，不重新绘制或裁剪。

| 动作           | 目录     | 帧数 | 原始尺寸  |
| -------------- | -------- | ---- | --------- |
| 趴姿晃头摆腿   | `lounge` | 8    | 192 × 208 |
| 站立轻晃       | `sway`   | 8    | 192 × 208 |
| 抱胸摸下巴踱步 | `ponder` | 8    | 416 × 208 |
| 等待确认       | `wait`   | 8    | 192 × 208 |
| 站着打盹       | `doze`   | 8    | 192 × 208 |
| 站立挥手       | `wave`   | 8    | 192 × 208 |

原始帧是 RGBA PNG。每组帧序为 `frame_01.png` 至 `frame_08.png`。`integrity.json` 保存整理前的 SHA-256 和字节数；构建检查逐一验证，确保整理没有改动图片。

动作显示名称、帧率、状态映射在 `app/shared/actions.ts` 中。所有动作按相同高度显示；踱步的宽画布用于保留移动范围，不能简单套用与其他动作相同的固定宽度。

菜单中复选框表示“禁用这个动作”。全部禁用时只显示站立第一帧；状态仍用文字和状态点表达。系统要求减少动态效果时也使用静态帧。菜单与输入框展开时暂停动作切换，防止输入期间角色位置变化。

增加动作时应同步修改素材清单、菜单配置和帧完整性校验。目前严格按用户提供的六组动作交付。
