## 免费优先与套餐边界

本项目采用免费套餐支持的 SQLite Durable Objects 与 WebSocket Hibernation API。图片直接转发，不使用 R2；客户端动画随 exe 提供，不消耗中继的静态文件请求。本次部署未创建、升级或修改任何付费订阅，也没有购买域名或服务器。

Workers Free 与 Durable Objects 的每日请求额度分别为 100,000；Durable Objects 另有每日 13,000 GB-s 的计算时长，以及读写与存储额度。两人日常使用预计可在免费额度内运行，但账号中其他应用也会消耗共享额度。免费套餐超限后相应操作失败，而非无限提供服务。[Workers 额度](https://developers.cloudflare.com/workers/platform/limits/)、[Durable Objects 额度与计费](https://developers.cloudflare.com/durable-objects/platform/pricing/)

本次最小 OAuth 授权可读取账号和部署 Worker，不能读取账号订阅；订阅 API 实测返回 HTTP 403。因此“方案兼容免费”已确认，“该账号当前一定是免费套餐”未确认。账号若已订阅付费套餐，按原套餐计算用量；不要把本次没有开通付费服务解读为对已有账号账单的零费用保证。可在 Cloudflare 的 Workers 计划页面核对原有套餐，无须为本项目购买新服务。

## 登录与后续部署

先确认登录的是项目预期账号：

```powershell
npx wrangler whoami
```

如果环境中已有其他账号的 `CLOUDFLARE_API_TOKEN`，它会优先于浏览器 OAuth 登录。只在当前终端清除该变量再登录，避免把程序部署到错误账号：

```powershell
$env:CLOUDFLARE_API_TOKEN = ''
npx wrangler login --scopes account:read workers_scripts:write
$env:CLOUDFLARE_ACCOUNT_ID = '目标账号 ID'
npx wrangler whoami
```

Wrangler 会额外请求保持登录所需的 `offline_access`。授权在 Cloudflare 的正式页面完成，不要把 API Token、密码或授权回调粘贴到仓库。

确认账号与权限后：

```powershell
npm run check
npm test
npx wrangler deploy
```

记录工具返回的 HTTPS 地址，访问 `/health` 应返回 `ok: true` 和协议版本 `1`。如果需要自有域名，在确认账号和域名权限后单独配置。

## 将地址写入免安装程序

```powershell
$env:DAFEYU_RELAY_URL = 'https://dafeyu.tap041120.online'
npm run package
```

也可复制 `.env.example` 为本地 `.env`，填写同一地址后打包。`.env` 不进入 Git，服务器 URL 本身不是密钥。不要向前端或客户端注入 Cloudflare 管理凭证。

同一个 exe 发给两台电脑。首次打开不需要安装运行时；启动时会将打包组件解包到临时目录，只有偏好设置保存在应用数据目录。自启指向原始 portable exe 的路径，不能指向临时解包文件。

## 网络和本地代理

1.0.2 桌面客户端优先使用系统代理；连接关闭、重置或超时后限时重试，并尝试隔离的直连 Session。成功路径用于后续 WSS，不改变系统代理，不跳过证书检查。创建配对的重试复用同一凭证，服务器返回同一配对码。若开发电脑已配置系统 HTTP 代理但终端请求失败，可在当前终端设置 `HTTPS_PROXY`／`HTTP_PROXY` 与 npm 代理变量，采用本机实际代理地址。不要关闭 TLS 证书检查。

Cloudflare 的全球域名与真实大陆网络之间是否可达，需要在两台实际电脑的日常网络分别验证；代理环境下成功不能替代不使用代理的实际验收。自有域名可用于部署，但不能直接视为可达性保证。

本次实测：原始 `dafeyu-pet-chat.anpeitao.workers.dev` 在系统代理下正常，当前电脑直接访问时超时。接入已有域名的 `dafeyu.tap041120.online` 后，不使用代理访问 `/health` 返回 HTTP 200，完整协议测试和真实 Electron 双客户端通信均通过。发布包使用后一个已验证地址。仍需两台实际电脑各自网络的验收。

线上复测可使用：

```powershell
$env:DAFEYU_TEST_RELAY_URL = 'https://dafeyu.tap041120.online'
$env:DAFEYU_TEST_DIRECT = '1'
npm run test:integration
npm run test:desktop-network
```

上述桌面测试通过 `DAFEYU_TEST_DIRECT=1` 强制直连；协议测试直连时应清除 `HTTPS_PROXY`／`HTTP_PROXY` 并关闭 Node 环境代理选项。终端测试需要代理时，另行显式配置当前代理与受信任系统证书，例如在支持这些参数的 Node 版本中使用 `node --use-env-proxy --use-system-ca scripts/integration.mjs`。正常桌面客户端优先遵循 Windows 系统代理并具备上述恢复逻辑，不依赖终端环境变量。
