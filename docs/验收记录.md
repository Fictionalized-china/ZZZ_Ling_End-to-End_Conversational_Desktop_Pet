# 铃宝验收记录

当前发布：**1.0.1**（2026-10-10）。更新低干扰界面与退出／异常断开的配对清理；使用既有 Cloudflare Worker 和域名，没有新增付费服务。

## 1.0.1 安静界面与配对清理

- 默认只显示人物和左上小气泡，三个点依次跳动。右键人物才显示自己的状态、菜单、置顶与缩放入口；Esc、收起按钮和失焦可收起操作栏。
- 点击气泡打开快捷回复，双击人物打开同时含历史、图片、输入框的完整聊天窗口。图片草稿在完整窗口确认，图片加载后最新图片滚到可见区域。
- 大气泡固定 296×184，背景镜像；长文在左右 48、顶部 44、底部 66 像素的安全内框滚动，图片仅显示【图片信息】。
- 连发每 3 秒平滑替换内容；没有下一条时第 4 秒开始渐隐，第 6 秒回到小气泡。状态和布局变化不会延长显示。
- 根因：旧中继只把断线标为离线，保留双方名额直到 7 天无活动；退出时 HTTP 清理与 1.8 秒进程退出竞争，可能来不及完成。
- 修复：通过现有认证 WSS 发送 leave 并等待结束确认，限时 HTTP 兜底；异常断开和加入后未连上各保留 30 秒，及时重连撤销期限，超时解除整组配对并通知另一方。静默失联先经过最多 45 秒心跳检测。兼容旧客户端带 Pair ended 原因的正常关闭。

## 0.2.0 交互与气泡更新

- 动作偏好由菜单迁入状态，六项启用开关和在线／忙碌切换均改为滑动开关。徽标显示自己的选择，对方情况和发送权限单独提示。
- 删除固定百分比大小面板，新增人物左上圆点，长按 180 毫秒后连续拖动缩放，范围 55%～135%。边缘处限制放大，不推动人物。
- 修复窗口上缘展开面板导致人物下移的问题：旧版在 x=40、y=30 的设置下，展开菜单后人物脚底从 y=270 变成 y=500，关闭后仍停在 y=500。新布局单独保存人物脚底中心锚点，面板／气泡只改变透明窗口外框。
- 人物下方常驻文字输入、图片选择与截图粘贴入口，Enter 发送、Shift+Enter 换行；双击人物或点击记录图标才打开会话历史。
- 用户气泡原稿保留，新增真正透明的运行衍生图。气泡按内容调整尺寸，长文换行／内部滚动，图片等比缩略并可预览；预先使用图片宽高，布局确认后显示，消除首次加载遮挡人物的瞬间。
- 连发通知按接收顺序单个显示，旧气泡先用两秒淡出，结束后再切换到下一条。关闭气泡或打开历史会收起待展示通知，历史列表保留；取消配对／退出则清空消息与计时器。

## 0.1.1 动画更新

问题：原第一个动作只有 8 帧；播放器按固定 8 秒轮换，打开／关闭面板时回到首帧。直接接入 4.5 秒的新动画会在半圈处被截断，因此同时更换素材和播放逻辑。

- 新趴姿使用用户目录里的 36 张 448 × 456 RGBA PNG，按原顺序、8 FPS、125 毫秒每帧、4.5 秒一圈循环。工程文件仅重命名，逐一对比原文件字节完全一致。
- 首尾相邻帧的 RGBA 平均绝对变化为 1.1888／255，小于其他相邻帧的最大值 1.4679／255；未复制首帧到末尾，避免接点额外停顿。
- 全部需要的帧先完成解码，随后通过 requestAnimationFrame 与时间轴绘制。默认循环超过原有 8 秒边界也不重置；多个动作轮换时等整圈结束。
- 默认仅开启趴姿，其余五个动作保留且停用。旧设置一次性迁移；大小、位置、置顶、自启、连接地址保留，后续手动选择正常保存。
- 所有帧共用覆盖非透明像素的固定显示范围，不改变源 PNG，不逐帧改变边界；当前帧 Alpha 用于透明区域穿透。
