# 铃宝第一版验收记录

日期：2026-10-09。版本：0.1.0。结论：已部署真实 Cloudflare 中继，接入账号已有域名并生成内置地址的免安装线上测试版。当前电脑不使用代理时，线上协议与真实 Electron 客户端通信通过；仍需 Win10／Win11 两台实际电脑及各自大陆网络的人工验收。

## 已完成内容

- 六组素材共 48 张透明 PNG 已整理至稳定路径，原始 SHA-256 全部匹配；踱步动作的宽画布保留。

- 文字、图片、剪贴板截图入口和预览已实现；消息只保留在内存；配对凭证不跨进程保存。
- Cloudflare Worker 与 Durable Object 实现双人房间、配对校验、状态门禁、心跳、重连、送达确认和消息去重。
- Git 忽略规则、依赖锁文件、素材校验与中文文档齐备。本地仓库为 main 分支，尚未设置远程或上传 GitHub。

## 授权与费用边界

先前环境 API 凭证属于其他账号，初次 OAuth 授权超时。本次用户完成新的 Wrangler 授权后，终端确认登录目标账号；部署时清除环境中其他账号的 API Token，并固定目标账号 ID。账号已有其他 Worker，本次只新增本项目服务。

使用免费套餐支持的 SQLite Durable Objects 与可休眠 WebSocket，不创建 R2、D1 或其他消息存储，不新增付费订阅、不购买域名或服务器；使用账号已有域名，不增加购买费用。授权不包含订阅读取权限，读取订阅返回 HTTP 403，因此没有把账号当前套餐确认为免费；已有账号的套餐规则和共享额度仍适用。没有向其他账号部署，也没有把管理凭证写入代码、文档或 exe。
