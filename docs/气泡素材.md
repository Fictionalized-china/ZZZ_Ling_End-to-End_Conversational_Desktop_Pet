原稿外围棋盘格是图片像素，不是真正的透明背景。使用内置 `imagegen` 的编辑模式生成透明衍生图，保留奶油色填充、深蓝蜡笔边框、尾巴、黄色星星和粉色装饰。没有调用外部图像生成 CLI，没有修改原稿或动画帧。

运行素材四角 Alpha 为 0，中心 Alpha 约为 253；真实 Electron Canvas 检查了外侧透明与内侧近乎不透明。PNG 内透明像素可能保留 RGB 色值，显示时以 Alpha 为准。CSS 仅缩放并略过外围透明留白：映射原图 x=32、y=128、宽 1488、高 752 的显示范围，不改变 PNG 字节。

## 最后一次编辑提示词

以下是内置工具最终透明清理所用的提示词；输入为依据用户原稿生成的第一版透明衍生图，输出保存为上述运行素材。工具没有提供可单独设置的模型／质量参数。

```text
Precise cleanup edit of this empty crayon speech bubble UI asset. REMOVE ALL diffuse navy, yellow and pink glowing halos outside the actual crayon strokes. No glow, no shadow, no vignette, no blur clouds whatsoever. Exterior pixels must be alpha 0, including between the stars/pink marks and the bubble. Keep only the cream filled speech bubble, its navy crayon outline and tail, the two yellow crayon stars, and four pink strokes. Keep their existing appearance and arrangement. Cream interior must be opaque, suitable for dark readable UI text. Do not add text. Tightly crop to the actual solid bubble and decorations with a small 8px transparent margin, wide landscape composition. Real transparent RGBA output; do not draw a checkerboard background.
```

## 显示边界

- 气泡宽 180～320 CSS 像素，内容高最多 150，含边框总高最多 220；长文自动换行并在内部滚动。
- 缩略图等比限制到 200 × 140，可点击在独立预览面板看图。图片尺寸随消息一起保存在内存中，首次显示前就预留正确位置，避免加载后盖住人物。
- 连发通知按接收顺序切换；旧气泡用 2 秒线性淡出，结束后才换内容。旧消息保留在本次会话历史中，桌面不会堆叠多个气泡。
- 开启 Windows 减少动态效果时关闭视觉淡出，仍沿用两秒的切换节奏。
