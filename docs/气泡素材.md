原稿外围棋盘格是图片像素，不是真正的透明背景。使用内置 `imagegen` 的编辑模式生成透明衍生图，保留奶油色填充、深蓝蜡笔边框、尾巴、黄色星星和粉色装饰。没有调用外部图像生成 CLI，没有修改原稿或动画帧。

运行素材四角 Alpha 为 0，中心 Alpha 约为 253；真实 Electron Canvas 检查了外侧透明与内侧近乎不透明。PNG 内透明像素可能保留 RGB 色值，显示时以 Alpha 为准。CSS 仅缩放并略过外围透明留白：映射原图 x=32、y=128、宽 1488、高 752 的显示范围，不改变 PNG 字节。

## 1.0.1 显示边界

以下保留 1.0.1 的历史说明。当前 1.2.0 的显示规则见文末。

- 小气泡固定 88×62 CSS 像素，默认靠近人物脑袋左上方，边缘处选择工作区内可用位置。
- 大气泡固定 296×184 CSS 像素，仅背景镜像，文字保持正向。文字安全内框左右各 48、顶部 44、底部 66 像素，强制裁切于内部，滚动条也不会越过外框。
- 气泡不显示图片本体，仅显示【图片信息】；点击可进入完整聊天窗口看图与预览。
- 连发按接收顺序每 3 秒切换，最后 250 毫秒淡出旧文字，换上新文字后渐显。边框位置与大小不变。
- 无待显示消息时，第 4 秒开始两秒渐隐，第 6 秒回到小气泡。状态通知、送达确认和布局变化不重新计时。
- 减少动态效果时关闭跳点和视觉渐变，仍遵循相同显示时序。

## 1.2.0 内容与比例

本次不重新生成图片，不修改原稿、两张运行气泡或动画帧。

人物为 55% 时，待机云为 88×62，消息云以此为最小尺寸，按实际文字测量增长，最大为 148×92；上限是 1.0.1 大气泡的宽高各一半。人物为 25%／100%／150% 时，上限分别为 67×42／269×167／404×251。字号限制在 11～16 像素，极小人物时优先保留可读的一行文字，必要时气泡高于最小值但不超过该比例上限。

消息内容区按气泡宽度的 48/296 留出左右边距，按高度的 44/184、66/184 留出上下边距；55% 最大气泡对应左右 24、顶部 22、底部 33 像素。达到上限后内部滚动，细滚动条同样位于安全区内。

双击大小气泡均打开便携输入框，图片提示也使用同一行为；双击人物或快捷框的历史按钮进入完整窗口查看图片。连发 3 秒替换、4 秒渐隐、6 秒恢复待机的时序不变，消息切换时按新内容重新计算尺寸。
